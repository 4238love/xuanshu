```java
    // - 直接使用数字
    // - 使用数字各位之和

// 6. 扩展模式（预留接口）

    // 可扩展更多起卦方式
```

**新项目实现：**

```typescript
// 只实现了时间起卦（对应原项目的模式0）
private generateGuaMa(): number {
    const year = date.getFullYear();
    const month = date.getMonth() + 1;
    const day = date.getDate();
    const hour = date.getHours();

    let shangGua = (year + month + day) % 8;
    let xiaGua = (year + month + day + hour) % 8;
```

```java
// 获取体用关系
public static String getLink(String shangGua, String xiaGua, String mark, boolean shangGuaYong) {
    String yongGua; // 用卦
    String tiGua;   // 体卦

    if (shangGuaYong) {
        yongGua = shangGua; // 上卦为用
        tiGua = xiaGua;     // 下卦为体
    } else {
        tiGua = shangGua;   // 上卦为体
```

## 四、时间起卦算法差异

### 原项目算法
```java
Map<String, Integer> diZhiShuMap = LiuYaoJiChuMap.DI_ZHI_SHU;
int yearNumber = diZhiShuMap.get(yearZhi);  // 使用年支数（1-12）
int monthNumber = lunar.getMonth();          // 农历月份
int dayNumber = lunar.getDay();              // 农历日期
int hourNumber = diZhiShuMap.get(hourZhi);   // 时支数（1-12）
```

**地支数映射：**
- 子=1, 丑=2, 寅=3, 卯=4, 辰=5, 巳=6
- 午=7, 未=8, 申=9, 酉=10, 戌=11, 亥=12

### 新项目算法
```typescript
const year = date.getFullYear();  // 使用公历年份（如：2024）
const month = date.getMonth() + 1; // 公历月份
const day = date.getDate();        // 公历日期
const hour = date.getHours();      // 小时数（0-23）
```

**问题分析：**
- ⚠️ 原项目使用农历和地支数（1-12范围）
- ⚠️ 新项目使用公历和小时数（0-23范围）
- ⚠️ 可能导致起卦结果不一致

**建议修正：**
```typescript
// 应该使用农历和地支数
const yearZhiIndex = DI_ZHI.indexOf(eightChar.getYearZhi()) + 1;
```
