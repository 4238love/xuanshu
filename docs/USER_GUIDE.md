## 快速开始

### 访问系统

1. 打开浏览器,访问系统首页
2. 首页展示六大排盘系统的入口卡片
3. 点击任意卡片进入对应的排盘页面

### 界面说明

每个排盘页面包含三个主要区域:

1. **输入区域**(顶部): 填写基本信息和选择参数
2. **操作按钮**(中部): 开始排盘、重置等操作
3. **结果展示区域**(底部): 显示排盘结果

## 八字排盘使用指南

### 功能介绍

八字排盘用于推算个人命理,分析五行、十神、大运流年等信息。

### 使用步骤

#### 1. 填写基本信息

| 字段 | 说明 | 是否必填 |
|------|------|---------|
| 姓名 | 被测者姓名 | 否 |
| 性别 | 选择男或女 | 是 |
| 日期类型 | 公历或农历 | 是 |
| 出生日期时间 | 格式: 2024-01-01 08:30:00 | 是 |

**日期格式说明**:
- 年份: 4位数字 (如 1990)
- 月份: 2位数字 (如 01-12)
- 日期: 2位数字 (如 01-31)
- 时间: 24小时制 (如 08:30:00)

**示例**:
- 公历: `1990-05-20 14:30:00`
- 农历: `1990-04-26 14:30:00`

#### 2. 高级选项(可选)

点击"高级选项"展开更多配置:

**真太阳时**:
- 启用后可根据出生地经度调整时辰
- 输入城市名称或经度值
- 推荐用于精确排盘

**显示选项**:
- 小运、流月、流日、流时
- 九星系统(5种体系)
- 神煞系统(60种神煞)
- 格局判断

#### 3. 开始排盘

点击"开始排盘"按钮,系统将计算并显示结果。

### 结果解读

#### 基础信息
- 公历和农历日期
- 性别、年龄、生肖、星座

#### 四柱八字
- 年柱、月柱、日柱、时柱
- 五行属性、纳音、空亡

#### 五行统计
- 木火土金水的数量
- 五行旺衰和缺失
- 喜用神建议

#### 十神系统
- 天干十神和地支藏干十神
- 十神格局分析

#### 大运流年
- 起运岁数
- 大运列表(每步10年)
- 流年列表和当前运势

## 六爻排盘使用指南

### 功能介绍

六爻排盘用于占卜预测,通过卦象分析事物吉凶。

### 使用步骤

#### 1. 填写基本信息

- 姓名(可选)
- 占事(必填) - 要占卜的具体事情
- 性别
- 起卦时间

**占事示例**:
- "本月生意能否成功"
- "是否应该跳槽"
- "与某某的婚姻如何"

#### 2. 选择起卦方式

**自动起卦(推荐)**: 系统随机生成
**日期起卦**: 根据时间计算
**手动起卦**: 自己投掷硬币输入

#### 3. 查看结果

系统显示本卦、变卦、互卦等完整信息。

### 结果解读

- **本卦**: 当前状态
- **变卦**: 未来发展
- **互卦**: 内在因素
- **六亲**: 子孙、妻财、兄弟、官鬼、父母
- **世应**: 世爻代表自己,应爻代表对方

## 常见问题解答

### Q1: 不知道准确出生时辰怎么办?

查看出生证明或询问长辈。如实在不确定,可尝试前后时辰对比。

### Q2: 公历和农历如何选择?

知道哪个就选哪个,系统会自动转换。

### Q3: 真太阳时需要使用吗?

普通排盘可不使用,精确排盘建议使用。

### Q4: 如何保存排盘结果?

可以截图保存或使用浏览器打印功能。

### Q5: 结果准确吗?

算法基于传统易学理论,计算准确,但解读需结合实际情况,仅供参考。
