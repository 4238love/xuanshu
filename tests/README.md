# 测试套件说明

## 目录结构

```
tests/
├── unit/                    # 单元测试
│   ├── bazi.test.ts        # 八字排盘单元测试
│   ├── liuyao.test.ts      # 六爻排盘单元测试
│   └── utils.test.ts       # 工具函数单元测试
├── integration/             # 集成测试
│   └── bazi-integration.test.ts  # 八字完整流程测试
├── comparison/              # 对比测试
│   └── algorithm-comparison.test.ts  # 算法对比测试
└── test.config.ts          # 测试配置文件
```

## 测试类型

### 1. 单元测试 (Unit Tests)
测试单个函数或模块的功能:
- 八字排盘核心算法
- 六爻排盘核心算法
- 通用工具函数
- 干支、五行、纳音计算

### 2. 集成测试 (Integration Tests)
测试完整的业务流程:
- 从输入到输出的完整流程
- 多个模块协同工作
- 边界情况处理
- 性能测试

### 3. 对比测试 (Comparison Tests)
对比新旧项目的输出结果:
- 四柱干支一致性
- 五行统计准确性
- 十神系统对比
- 神煞系统对比
- 卦象结果对比

## 运行测试

### 安装测试依赖
```bash
npm install --save-dev jest @types/jest ts-jest
```

### 配置 Jest
在 `package.json` 中添加:
```json
{
  "scripts": {
    "test": "jest",
    "test:watch": "jest --watch",
    "test:coverage": "jest --coverage"
  },
  "jest": {
    "preset": "ts-jest",
    "testEnvironment": "node",
    "roots": ["<rootDir>/tests"],
    "testMatch": ["**/*.test.ts"],
    "collectCoverageFrom": [
      "lib/**/*.ts",
      "!lib/**/*.d.ts"
    ]
  }
}
```

### 运行测试命令
```bash
# 运行所有测试
npm test

# 运行特定测试文件
npm test bazi.test

# 监听模式
npm run test:watch

# 生成覆盖率报告
npm run test:coverage
```

## 对比测试流程

1. **准备测试数据**: 使用相同的输入参数
2. **运行新项目**: 获取新项目的输出结果
3. **对比原项目**: 与原项目输出进行对比
4. **记录差异**: 记录所有不一致的地方
5. **分析原因**: 分析差异产生的原因
6. **修正算法**: 根据分析结果修正算法

## 测试覆盖率目标

- 核心算法: 90%+
- 工具函数: 95%+
- 业务逻辑: 85%+
- 整体覆盖率: 85%+

## 注意事项

1. **测试数据**: 使用真实的测试数据,覆盖各种边界情况
2. **断言准确**: 确保断言条件准确,避免误报
3. **性能测试**: 关注算法性能,确保响应时间合理
4. **错误处理**: 测试各种错误情况的处理
5. **文档更新**: 测试用例变更时及时更新文档
